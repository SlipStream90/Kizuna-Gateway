# Self-hosted fonts

`noto.css` and `noto/*.woff2` are Noto Sans JP (400/500/700) and Noto Serif JP
(400/500/600), downloaded from Google Fonts on 2026-10-24 with the CSS rewritten to
local paths. Browsers fetch only the unicode-range subsets a page uses.

They are hosted locally so pages render without depending on fonts.gstatic.com
(slow or unavailable networks at demo venues).
