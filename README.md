# Kizuna Gateway

Kizuna Gateway is a demo-safe market-entry decision-support platform for Japanese SMEs evaluating expansion into India. It brings together four connected engines:

- Market Intelligence
- Partner Trust Engine
- Compliance Copilot
- GTM Simulator

The repository is being built as a vertical-slice MVP from the supplied product requirements. It will use deterministic seeded data and make evidence coverage, assumptions, and limitations visible throughout. It will not claim live government integrations, legal advice, or verified partner trustworthiness.

## Development status

Foundation and implementation branches are being established. See `docs/PRD.md` for the working specification and `docs/IMPLEMENTATION_PLAN.md` once the Cressida mission has completed its architecture and planning stages.
